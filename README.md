# Newspack Multibranded Site plugin

Brand different content and sections of your site with unique colors and navigation.

## Features

- **Multi-Brand Taxonomy**: Assign brands to posts, pages, and custom content types
- **Primary Brand Selection**: Choose a primary brand when content belongs to multiple brands
- **Custom Branding Elements**: Brand-specific logos, colors, menus, and navigation
- **Hierarchical Brand Structure**: Support for nested brand relationships (e.g., `/parent-brand/sub-brand/`)
- **Newspack Integration**: Works seamlessly with Newspack Popups and Newspack Collections
- **Frontend Customization**: Automatic body classes and theme color overrides per brand
- **Sports Data Support**: Integration with sports data providers for team and competition information

## Supported Content Types

The brand taxonomy can be applied to:
- Posts and Pages (built-in)
- Newspack Popups (when Newspack Popups plugin is active)
- Newspack Collections (when Newspack Collections plugin is active)
- Custom post types via filters
